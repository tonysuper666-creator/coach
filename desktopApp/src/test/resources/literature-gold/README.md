# Literature candidate gold set

These are page excerpts from the public test library. The three PDFs retain the source fonts, glyph positions, line breaks and rules. Text outside the sampled blocks was removed. The TSV labels were transcribed from the source pages before running candidate extraction. Each row identifies the fixture, its one-based reader page, one of five roles, and the typeset text. Body and note rows are sentences. Margin, caption and bibliography rows can also be labeled fragments.

Run `:desktopApp:test --tests '*LiteratureGoldTest'` through the repository's heavy runner. Recall counts whole body sentences at the labeled page. Unexpected candidates, including note fragments, fail the check. The citation check uses the page text as its OCR response to isolate candidate selection and anchor consistency.
