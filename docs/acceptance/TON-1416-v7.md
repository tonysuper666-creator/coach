# TON-1416 · Android V7「案头」验收

V7 的颜色和基本尺寸来自批准的 `CoachV7.kt`；三种窗口尺寸和段间距来自同包 `V7.json`；周数显示字号和全部纸面/菜单/选项/按钮投影来自同包参考 HTML。投影由 `import-v7-surfaces.py` 自动生成，包含深色内阴影；不使用 Material elevation 近似。`tools/design/import-v7.py` 导入它们，生成 `coach.design.tokens`，只将 Android 专用的 `FontChain` 接到 `V7Fonts.android.kt`。完整 JSON 留在 `tools/design/V7.json`，便于与 `CoachV7.swift` 对照。

`Desk` 负责纸面、目录、页边和专心读。`TodayScreen` 已选择的周使用 `WeekPage`；`StudyScreen` 和 `MainlineScreen` 继续使用原有控制器、账本、提交标识及重试逻辑。原有课程文本、答案键和网络接口均未修改。

## 字体与动态效果

- 正文、标题：Literata + Noto Serif SC；界面：IBM Plex Sans + Noto Sans SC；编号：IBM Plex Mono；个人批注：IBM Plex Sans + LXGW WenKai。
- 中文使用设计包的 subset 文件。Android `Typeface.CustomFallbackBuilder` 先西文、再中文、再系统字体；西文子集移除间隔号、破折号、中文引号及省略号，使这些标点落到中文字体。修改后的西文字体使用应用专用内部名称，并附 OFL 许可。
- 页面 300ms、展开 260ms，专心读进出 180ms 纯淡入。监听 `ANIMATOR_DURATION_SCALE`，为 0 时关闭动画。状态保留测试覆盖专心读、折叠切换中的草稿和选择；减弱动态测试在不推进动画时钟的情况下检查纸面的实际像素。
- 窗口判断使用扣回软键盘高度的尺寸，外屏横拿保持单栏。专心读保留同一个阅读组合与滚动状态，收起目录、页边和输入区。
- 现有 Markdown 脚注显示为上标；页边按标记所在行定位，冲突时先向下顺延，再从底部回收；长批注仍保留滚动且不重叠。窄屏的出处改为随文卡片，避免收起页边后丢失引用。数学公式继续走现有渲染器。

## 视觉退回后的修正

顶栏使用独立的左、中、右三区；内页保留 Coach 品牌入口并把原有五个导航入口放进菜单，外屏显示四个紧凑导航入口。完成的阅读正文使用轻量整节题目链接、章节页脚及按正文行对齐的页边卡；追问和出题仍调用原有控制器。周页保留类型、混合学习状态、统计条、下一步和相邻周导航。答题保留幂等提交、失败重试、猜测标记、归档和桥接入口，讲解改为正确答案/错选项分组，其余选项的原因和归档状态仍可向下滚动查看。

Compose 所有阅读文字明确使用完整行高，避免默认裁切单行留白。外屏周页按参考使用 1.45 倍标题行高，内屏使用 1.85；横屏和竖屏答题动作固定在底部，各占一半宽度，正文可视区域避开动作栏。截图同时断言选项间隔为 10dp、正确与错选标签存在；页边回收的三项边界测试和品牌菜单的记录入口测试也已覆盖。
