# TON-1416 · Android V7「案头」验收

V7 的颜色和基本尺寸来自批准的 `CoachV7.kt`；三种窗口尺寸和段间距来自同包 `V7.json`；周数显示字号来自同包参考 HTML。`tools/design/import-v7.py` 导入它们，生成 `coach.design.tokens`，只将 Android 专用的 `FontChain` 接到 `V7Fonts.android.kt`。完整 JSON 留在 `tools/design/V7.json`，便于与 `CoachV7.swift` 对照。

`Desk` 负责纸面、目录、页边和专心读。`TodayScreen` 已选择的周使用 `WeekPage`；`StudyScreen` 和 `MainlineScreen` 继续使用原有控制器、账本、提交标识及重试逻辑。原有课程文本、答案键和网络接口均未修改。

## 字体与动态效果

- 正文、标题：Literata + Noto Serif SC；界面：IBM Plex Sans + Noto Sans SC；编号：IBM Plex Mono；个人批注：IBM Plex Sans + LXGW WenKai。
- 中文使用设计包的 subset 文件。Android `Typeface.CustomFallbackBuilder` 先西文、再中文、再系统字体；西文子集移除间隔号、破折号、中文引号及省略号，使这些标点落到中文字体。修改后的西文字体使用应用专用内部名称，并附 OFL 许可。
- 页面 300ms、展开 260ms，专心读进出 180ms 纯淡入。监听 `ANIMATOR_DURATION_SCALE`，为 0 时关闭动画。状态保留测试覆盖专心读、折叠切换中的草稿和选择；减弱动态测试在不推进动画时钟的情况下检查纸面的实际像素。
- 窗口判断使用扣回软键盘高度的尺寸，外屏横拿保持单栏。专心读保留同一个阅读组合与滚动状态，收起目录、页边和输入区。
- 现有 Markdown 脚注显示为上标；页边按标记所在行定位，冲突时向下顺延并可滚动。窄屏的出处改为随文卡片，避免收起页边后丢失引用。数学公式继续走现有渲染器。

```powershell

$env:GRADLE_USER_HOME = 'D:/agent/gradle-home'
$env:Path = "$env:JAVA_HOME/bin;$env:Path"
(Get-Counter '\Memory\Available MBytes').CounterSamples[0].CookedValue
.\gradlew.bat :androidApp:assembleDebug :androidApp:testDebugUnitTest :shared:domain:jvmTest :shared:protocol:jvmTest :shared:client:jvmTest :shared:ui:jvmTest '-Proborazzi.test.record=true' --console=plain
```
