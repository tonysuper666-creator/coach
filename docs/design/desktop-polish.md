## 2. 名字与 logo（李政 11-16 交给本卡定）

### 界面里的名字

结论：**界面内的品牌位保留短名「Coach」**，小号无衬线、`uiStrong`，不换成全名，也不加图形。全名 LearningCoach 只出现在安装包、exe、开始菜单、窗口标题栏和关于页（TON-1656）。

理由：
1. V7 顶栏是一行 48dp 的小号标签，左边字标后面紧跟「目录」「返回书架」，中间是书名。全名有 13 个字符，宽度约为「Coach」的 2.5 倍，阅读页上会把面包屑往右挤，窄窗（1/2 贴靠）时和书名相撞。
2. Windows 的标题栏就在顶栏正上方，已经写着「LearningCoach」和图标；窗口内再写一遍全名是重复。成熟的 Windows 应用（Word、设置、Edge）窗口内都不重复全名。
3. 「Coach」本来就是 V7 设计包顶栏里的写法，`Desk.kt` 和 `WindowsTextbookHost.kt` 已经是它，保持不动最省、也不和设计包分叉。
4. 不加 logo 图形：顶栏是「定稿」的页眉，只有字；图形留给标题栏左上角、任务栏和开始菜单。

TON-1656 第 3 条按此收尾：顶栏字标不改字，只确认窗口标题栏是全名。

## 6. 书页感

李政 11-16 看了效果图后说：「阅读器给我的感觉不错，但是没有那么像读书的感觉。」美学不变，还是 V7「案头」。这一节要做的是把那张「纸」排成真正的书页，不是换风格。优先级高于第 4 节 P3 及以后的卡。

现在为什么不像书（main `ff84843c`，`books/TextbookReader.kt:198-250`）：

- 一个导入页最多 4000 字（`TextbookExtraction.paginate`），整页放进一张可以滚动的纸。读的时候是在网页上往下滚，不是一页一页地读。
- 段落之间用原文的 `\n\n` 隔开，所以段间空一整行，首行不缩进，左对齐，右边参差不齐。PDF 文字层里的硬换行也照原样显示，一段话会在半行处断开。
- 纸上只有正文：没有书眉，纸上没有页码（页码在纸外的按钮栏里），章首页和普通页长得一样。

李政当天又补了一句：「教材里有很多特殊排版，这个做到阅读器里就完全看不出来了。」所以 PDF 改为默认看原版（6.6，TON-1670），文字版里重排会走样的块从原页裁下来嵌回去（6.7，TON-1669）。两者都放在同一张纸、同一套书眉页脚里。

### 6.1 段落

**中文段落**（一段里汉字占多数就算中文段落）

- 首行缩进 2em（两个汉字宽），段与段之间不空行；行距仍用 V7 正文行距 1.85。
- 两端对齐（`TextAlign.Justify`），最后一行左对齐。
- 标点挤压：给正文开字体特性 `chws`（打包的 `noto_serif_sc.ttf` 带这个特性，已核对）。行首行尾禁则交给系统断行，交付时在截图里找一处行首附近的逗号核对。
- 中英混排时，汉字和西文、数字之间不手动插空格。原文有空格就照原样显示，原文没有也不补。

**西文段落**

- 首行缩进 1em，段间不空行；标题后的第一段不缩进（西文书的惯例）。
- 左对齐，右边参差，不做两端对齐。桌面版 Compose 没有自动连字符，强行两端对齐会出现一条条白色的「河」。以后能断字了再改成两端对齐，记在「以后再说」。

**不缩进的块**（中英文都一样）：标题、列表项（`-`、`1.`、`（1）` 开头）、表格行、代码、公式行、单独一行的图注、引文块（`>` 开头）。这些块保留原来的换行，块前后各留 V7 `Space.s3`（12dp）。

**标题**：Markdown 标题照旧把井号隐去。一级标题用 `headlineLarge` 宋体，其他级别用 `titleLarge`。标题上方留 V7 `Space.s7`（32dp），下方留 `Space.s3`，不再叠加原文空行造成的那一行（这一条就是第 5 节 B1 里的「标题前留白过大」）。

**显示串和原文逐位对应（这是硬约束）**：段落排版只能改「怎么显示」，不能删字也不能加字。显示用的字符串必须和页文字一样长，同一个下标指向同一个原文字符。这样批注、高亮、选段、讲解出处的 UTF-16 偏移才能一个都不变。做法：

- 段与段之间多出来的那个 `\n`，换成同样占一个下标、但不显示的字符，或者把它所在的位置排成零高度，让空行消失。
- PDF 一段话里的硬换行：两边都是汉字时换成零宽字符，两边都是西文时换成空格，各占一个下标。
- 原文、`page.text` 和导入时存的数据都不改。复制选中的文字时，复制出来的应该是原文。做不到就在交付里写明差在哪，不能悄悄改成复制显示串。

### 6.2 翻页还是滚动

- **翻页**（文字版第一次打开时的默认；原版的默认见 6.6）：一屏就是一页，排满为止，不出现纵向滚动条。文字版可跨导入页排版，导入页边界只标记来源；可确认的章首提前换页。
- **孤行和标题**：段落最后一行不单独落到下一页顶上，第一行也不单独留在上一页底下（四行以上的段落，页首页尾至少各留两行）。标题不放在页面最后一行，跟着下一段一起挪到下一页。最后一行要么完整显示，要么整行挪到下一页，不会被下面的栏挡住半行（第 5 节 B1）。
- **双页对开**（6.9「版面」选「自动」时；选单页、双页见 6.9）：两张纸在书脊处相接，像一本摊开的书，不再是一张纸中间留空。每张纸就是一个单页：版心（正文栏宽 33em）+ 外侧页边 64dp（`Layout.mainPx`）+ 书脊那侧页边 48dp（`Space.s8`），两页正文之间隔 96dp。
  - **分界宽度**：阅读区（纸面所在的那块桌面，不含页边栏）≥ 2 ×（栏宽 + 64dp + 48dp）+ 2 × 24dp（书两侧露出的桌面，`Space.s6`）时排双页。中号字是 2 ×（594 + 112）+ 48 = 1460dp，小号约 1342dp，大号约 1638dp，跟着 Aa 变。拖窗口时在分界附近不来回闪：变宽到分界才切双页，变窄到「分界 − 24dp」才回单页。窗口多宽才到 1460dp 要看页边栏开没开，交付截图时注明。
  - 单页还是双页由阅读器按上面算好，作为参数交给 TON-1671 的翻页组件，组件自己不算。原版的分界见 6.6。
  - **书脊**：每张纸靠书脊的一侧画一条 24dp 宽的渐暗，书脊处最深，往外渐变到无。起点值：浅色 `ink` 6% 透明度，深色黑色 24%。和参照图并排看，以「看得出是两张纸，又不脏」为准，定下的数写回本节。数值写在翻页组件里，不进 V7 token。
  - **纸和桌面**：两张纸合成一块放在 V7 `desk` 上，沿用现在纸面的 `paperShadow("sheet")`，只在整块外面画一次。外侧四个角用 `Radius.sheet`，书脊那侧不圆角。不画页块厚度和精装封面，不做 3D 倾斜和页面弯曲。
  - 章首页不强制放在右页，不为此插空白页。翻页时两页一起翻。
- **滚动**（李政说的「竖着滑着读」，给偏工具类的书）：在阅读设置（6.9）的「阅读方式」里切换「翻页 / 滚动」，按书记住。界面上写「滚动」不写「滑动」，因为「滑动」已经是翻页效果的一种，苹果「图书」也是这样分的。翻页和滚动**功能完全对等**：插图和裁图块、选字讲解和提问、高亮批注的显示和编辑、出处跳转、跨页选字、目录和搜索跳转、换字号字体后位置不丢、两种方式来回切停在同一句，这 8 项哪一种都不少。逐格对照的是 TON-1671 卡上的对等表（翻页、滚动 × 原版、文字版，共 32 格），见 6.9 放出标准第 5 条。
  - **文字版**：整本书连成一条往下流，正文栏宽和段落照 6.1，没有左右页，不用翻页效果，版面只排一栏。一章是一张纸，章与章之间露出 24dp（`Space.s6`）桌面；每章开头照 6.3 的章首页排（大号章号、章名），章内不断开。插图和裁图块照原文锚点放，不挪位置（6.5、6.7 的挪图只在翻页时用），尺寸规则不变。
  - **原版**：见 6.6。
  - **原书页码**：每个导入页从哪一行开始，就在那一行旁边的外侧页边写页边码（6.4）。地脚位置固定一行小字「第 42 页」（`Size.cap`、`fgTertiary`、数字字体），取屏幕上方 1/3 处那一行所在的导入页，滚动时跟着变，和出处里的页码是同一个数。不显示书眉，不显示排版页页码和「本章还剩 N 页」。
  - **操作**：滚轮、触控板惯性照系统，不另加惯性和吸附。空格、PageDown 往下一屏（上一屏最后两行留在新一屏顶上），Shift+空格、PageUp 往上；Home、End 到书首书尾；← → 不翻页。右侧 `V7Scrollbar`，长度按整本书算。出处跳转滚到被引那段，第一行落在屏幕上方 1/3 处，用 `hl` 框出来。
  - **不卡**：只排版和渲染屏幕前后各约两屏的内容，其余先按估算高度占位，滚近了再排；排好后保持屏幕上那一行不动，画面不跳。2560×1440、150% 缩放下连续滚动，帧耗时 p95 不超过 16 毫秒。
  - **翻页和滚动来回切，停在同一句话上**：切之前取当前位置的文字偏移（滚动时取屏幕上方 1/3 处那一行的第一个字，翻页时取本页第一个字），切过去以后滚动就让这个字所在的行落在屏幕上方 1/3 处，翻页就翻到包含这个字的排版页。来回切 10 次，位置不漂。
- **翻页动画**（TON-1671 照这里做）：翻页效果有「翻转 / 滑动 / 无」三种，在 6.9 的阅读设置里选，默认「翻转」。「卷页」（纸跟手弯成曲面）做到 6.9 的标准以后才放出来，放出来就改成默认。
  - **翻转**：双页时右页绕书脊翻到左边，往回翻时左页翻到右边；单页时整页绕左边缘翻。翻过 90° 以后看到的是这张纸的背面，也就是新的左页。翻起的页在下面那页上投一道阴影，纸越接近竖直阴影越深，最深处浅色 `ink` 12%、深色黑色 30%。浅色模式下翻起页的背面淡淡透出正面的镜像字（6% 透明度），深色模式不透。静止的页不透字。用 `graphicsLayer` 的 `rotationY` 和 `cameraDistance` 做透视，镜头距离以翻到 90° 时纸的近边不超出窗口为准。
  - **滑动**：整个对开（单页时就是那一页）横向滑出，新的一组从另一侧滑进来，两组之间露出 24dp 桌面。
  - **无**：直接换页，0ms。
  - **时长和曲线**：点击、键盘、滚轮翻页用 `Motion.pageMs` 300ms。曲线不用 V7 的回弹曲线：`Motion.easing` 会冲过头，纸落下时像穿进桌面。改用不回弹的减速曲线 `CubicBezierEasing(0.2f, 0f, 0f, 1f)`，写在组件里，不新增共用 token。
  - **跟手**：拖页角或页边、触控板双指横扫、触屏横向拖，纸都跟着手走，不设时长。松手时过了一半，或者朝翻页方向甩得够快（≥ 1000dp/s），就翻过去；否则回原位。剩下那段的时长按剩余比例算，在 120–300ms 之间。触控板一次轻扫最多翻一页。
  - **在哪里能翻**：只在版心外面。外侧页边整条（单页时左右两条）都能点、能拖；页角 48dp × 48dp 里鼠标变成手形，选「翻转」时悬停会让页角微微翻起约 6°（滑动和无没有这个提示）。版心里的点击和拖动一律是选字，不翻页。
  - **多页跳转**（Home、End、跳转框、打开出处跨了不止一页）：翻转时连着翻过最多 5 张纸，一张接一张错开，总共约 450ms（1.5 × `pageMs`），中间的纸只画纸面不画字；滑动时直接滑到目标页；只差一页时照普通翻页。
  - **跨页选字**：拖选到最后一页（双页时是右页）外侧边缘，停 600ms 就自动翻到下一页，选区接着往后延伸；拖到第一页外侧边缘停住就往回翻。停的时候在边缘显示一行小字「继续按住，翻到下一页」（`Size.cap`，`fgTertiary`）。双页时从左页拖到右页不用翻页。
  - **翻页时不重排**：翻之前把要动的页画成位图缓存，动画只移动位图；高亮、批注记号、出处框都在位图里，翻起的页上照样看得见。2560×1440、150% 缩放下拖页角，帧耗时 p95 不超过 16 毫秒。
  - **减弱动态**：系统「动画效果」关掉时（`rememberReducedMotion()`，读 Windows 的 `SPI_GETCLIENTAREAANIMATION`），不管选的是哪种效果都直接换页；拖动时纸不跟手，松手后按拖的方向直接换页。
  - TON-1671 合并之前，TON-1667 先用 150ms 淡入（`Motion.pageMs` 的一半）顶着，合并后换成组件。
- **键盘和 TON-1658 对齐**：TON-1658 先把 ← / → / PageUp / PageDown / Home / End 接上（那时翻的还是导入页）。书页上线时，同一组键改成翻排版页：←、PageUp 上一页，→、PageDown、空格下一页，Home、End 到本章首页、末页（这是翻页时；滚动时 Home、End 到书首书尾，见上面「滚动」）。焦点在输入框或批注里时不翻页（TON-1658 已有）。鼠标滚轮在翻页模式下按一格翻一页，并做节流，触控板一次轻扫最多翻一页。

### 6.3 书页本身

单页时的版式（数字都按中号字，随 Aa 缩放）：

```
┌──────────────── 纸面 ────────────────┐
│ 天头 52dp（Layout.mainPt）              │
│   书眉：章名  ·  cap 12sp  fgTertiary     │
│ ──────────── 版心 594dp ─────────────   │
│   正文……                                │
│                                         │
│   ———— （脚注分隔线，版心 1/3 宽）         │
│   ¹ 脚注 cap 12sp                        │
│ 地脚 64dp（Layout.mainPx）              │
│   页脚：第 42 页          本章还剩 6 页    │
└─────────────────────────────────────────┘
```

- **天头地脚**：天头 52dp，地脚 64dp，地脚比天头略宽，这是纸书的老比例。版心宽度仍然是正文栏宽（33em）。单页时一张纸居中，版心左右各留 64dp；双页时外侧留 64dp，书脊那侧留 48dp（6.2）。
- **书眉**：放在天头里，在本页版心上方居中，用 `Size.cap` 12sp、`fgTertiary`，字距用 `Tracking.cap`，不加粗、不加线。单页时显示章名；双页时左页显示书名，右页显示章名，和中文书的习惯一样。章首页不显示书眉。章名取这一页之前最近的那个标题（和 `BookText.chapterTitle` 同一条规则）。书名取元数据，没有元数据时才用文件名。
- **页脚**：外侧写出处页码（见 6.4），用 V7 数字字体 `LocalV7Fonts.numbers`、cap 12sp、`fgSecondary`。内侧写「本章还剩 N 页」，`fgTertiary`；本章最后一页写「本章完」。单页时出处页码在左、剩余页数在右；双页时出处页码分别放在左页的左下角和右页的右下角（外侧），剩余页数只在右页写一次。
- **章首页**：书眉不显示，标题往下沉，从版心顶部往下留出版心高度的 1/4。章号和章名的排法照 V7 周页的大号周数（`Desk.kt` 的 `PageHeader(week = …)`）：章号用 `display` 字体、Light、48sp × 字号缩放，补成两位（`03`），字距 −0.03em；右边底对齐放章名，用 `headlineLarge`。章号从标题文字里认：「第三章」「第 3 章」「Chapter 3」「3 需求分析」开头的数字都算。认不出就不放章号，只放章名，不编号。ereader.space 的章首页是章名居中、上面一行小字「第一章」；我们保留 V7 的大号章号，这是 V7 认得出来的地方，外观不换。
- **脚注**：脚注落在引用它的那一行所在的排版页底部，上方画一条细线（`line` 色，1dp，版心 1/3 宽），字号 cap 12sp。正文里的脚注号用上标数字，点它跳到页底的那条脚注。现在导入时还认不出脚注（PDF 的脚注混在正文里，EPUB 的 `noteref` 没保留），所以本节只定显示规则。识别脚注归导入那边，记在「以后再说」，要做的时候和 TON-1663、TON-1665 一起排。
- **底栏**：纸面下面只留一条细栏，左边「上一页」，中间是页码跳转框，右边「下一页」。框里平时显示「第 42 页」，点一下变成输入框，回车跳转，不再单独放一个「前往」按钮。纸外原来的「42 / 300」和纸上的页脚重复，去掉。这一条就是第 5 节 B1 的「分页按钮和页码放进同一条底栏」。

### 6.4 两种页码

- **排版页只管显示**。排版页按窗口大小、字号、单双页实时算，不保存、不出现在出处里，也不改导入时存的页和任何偏移。阅读进度照旧记导入页（`onPage`）：翻到哪个排版页，就记这一页第一个字所在的导入页。重新打开时，回到包含那个导入页开头的排版页。
- **出处页码看得见**。页脚写的「第 42 页」和出处、讲解里写的「第 42 页」是同一个数（都是 `book.pageLabel`），PDF 就是 PDF 原文件的页码。一个排版页跨了两个原书页时：
  - 新的那一页从哪一行开始，就在那一行旁边的页边空白里写一个小号的原书页码（`42`，数字字体、cap 12sp、`fgTertiary`，单页时写在版心外侧，双页时写在各页外侧）。这是学术书里常见的「页边码」。
  - 页脚写成「第 41–42 页」。
- **打开出处**时，跳到包含被引那段话的排版页，高亮照旧。高亮跨页时，跳到高亮开头所在的那一页。
- **跳转框**输入的是出处页码，跳到包含那个原书页开头的排版页。
- **「看原页」升级成 PDF 的默认视图「原版」**，摆法和两种视图互相切换时的位置规则见 6.6。
- PDF 自带印刷页码（PDF 第 50 页印着「42」）时，现在的出处写的是 PDF 页码，书页上也写 PDF 页码，两边保持一致。以后要改成用印刷页码，两边一起改，记在「以后再说」。
- 原来那句常驻备注「页码按 PDF 原文件计算。」由 TON-1658 收进页码的悬停提示。书页上线后，提示挂在页脚的出处页码上。

### 6.5 插图（显示规范，抽图由 TON-1665 做）

- **位置**：插图放在原文的锚点位置，单独成一块，前后各留 `Space.s4`（16dp）。插图不插进文字串（TON-1665 第 1 步已经定了这一点），所以偏移不受影响。
- **尺寸**：宽度取「原图宽（按 1 倍密度）」和「版心宽」里较小的那个，居中。小图不放大。高度不超过版心高的 85%，这样图注能和图在同一页；超过就按比例缩小。
- **分页**（翻页时；滚动时照原位放）：图和它的图注不拆到两页。这一页剩下的地方放不下这张图，就把图挪到下一页开头，这一页空出来的地方用图后面的正文补上，不留大块空白。图最多往后挪一页，不挪出本章；连着几张图都要挪的，按原顺序排在下一页开头。比一整页还高的图连图注一起按上面的 85% 缩到一页内。双页时每页各排各的，图不跨书脊；挪到下一页就是左页挪到右页、右页挪到下一个对开的左页。原文里「见图 3-2」这类说法不改。图本身不在文字串里，挪位置不改任何偏移。
- **图注**：放在图下方 `Space.s2`（8dp），`Size.note` 15sp，`fgSecondary`，正文字体。只有一行时居中，多行时左对齐、和图同宽。「图 3-2」这种编号照原样显示，不另加粗。
- **点开放大**：点图打开一个和阅读页同一种纸色的覆盖层，图在窗口里尽量放大，但不超过原图大小，下面带图注。按 Esc、点图外面、或者点右上角「关闭」都能退出。覆盖层打开时方向键不翻页。不加缩放、旋转、下载（这些算新功能）。
- **深色模式**：图片不反色，也不调亮度和色温。图垫在一块浅色纸底上（取浅色主题的纸色），四周留 8dp，圆角 `Radius.s`，这样透明底的线图在深色纸上也看得清。浅色模式不垫底，图直接放在纸上。
- **加载**：图还没加载出来时，用和 TON-1658 页图占位同一种纸面占位，尺寸按图的宽高先留好，图到了直接替换，版面不跳。
- 讲解和出处指到插图时（「第 42 页 · 图 3-2」），打开后图上加一层和文字高亮同色（`hl`）的 2dp 外框。

### 6.6 原版页（显示规范，PDF 默认视图，由 TON-1670 做）

原版就是把 PDF 原页当成书页本身：原页图放在 6.3 那张纸的版心位置（宽度不受 33em 栏宽限制，按下面的公式由原页宽高比和窗口算出），书眉和页脚照 6.3 写在原页外面的天头和地脚里。原页上自己印的页眉、页码照原样留着，不遮、不裁。

```
┌──────────────────── 纸面 ────────────────────┐
│ 天头 52dp   书眉：章名（cap 12sp fgTertiary）      │
│        ┌──────────────────────┐                │
│        │                      │                │
│        │   原页图（不加框、     │  ← 批注记号     │
│        │   不加阴影）          │    画在这一侧    │
│        │                      │                │
│        └──────────────────────┘                │
│ 地脚 64dp   第 50 页              本章还剩 6 页     │
└───────────────────────────────────────────────┘
```

- **两种阅读方式「翻页 / 滚动」**，和文字版是同一行（6.9「阅读方式」），用同一个组件（TON-1671）。原版和文字版各记一个，按书记住。PDF 原版第一次打开默认**滚动**：李政 11-16 说工具类的书想一路往下滑着读，PDF 教材、讲义多是这一类；切到文字版默认翻页。不按书名或内容猜「是不是工具书」，猜错了比不猜更烦。原来的「整页 / 页宽」合进这两种，不再单列。
  - **翻页**（原来的「整页」）：一屏放下一整页，不出现纵向滚动条。原页高 = 纸面可用高 − 天头 52dp − 地脚 64dp，宽按原页宽高比算；左右留白不到 64dp 时改按宽度缩，高度跟着变小，上下居中。
  - **滚动**（原来的「页宽」，改成页与页连起来）：原页一页接一页竖着排，每一页是一张纸放在 `desk` 上，纸和纸之间露出 24dp（`Space.s6`）桌面。原页宽 = 阅读区宽 − 2 × 64dp，但最宽只到「原页正文和文字版正文一样大」（按 6.7 统计的这本书正文中位字号换算；常见 A4 教材约 1070dp），再宽就居中，两边露桌面，免得大屏上字大得要转头看。不显示书眉和「本章还剩 N 页」，原书页码照 6.2 滚动时的做法：每页纸外侧上角旁写页边码「50」，地脚位置固定一行「第 50 页」。浅色下原页的白底就是纸，用 `Radius.sheet` 和 `paperShadow("sheet")`；深色下照下面「深色模式」。只排一栏，版面那一行灰掉。操作和「不卡」同 6.2 的滚动。
- **宽屏双页**：翻页时，两张纸在书脊处相接，纸、桌面和书脊渐暗都同 6.2。每张纸 = 整页宽 + 外侧 64dp + 书脊那侧 24dp：原页自己带白边，书脊那侧不用再留 48dp，24dp 的书脊渐暗正好落在这条边里，不压到原页图。阅读区宽 ≥ 2 ×（整页宽 + 88dp）+ 2 × 24dp 时自动排双页（6.9「版面」选「自动」时），拖窗口时同样留 24dp 余量不来回闪。整页宽就是上面按高度算出来的宽，所以分界跟着原页的宽高比和窗口高度走，不用 6.2 的正文栏宽。横版页（宽大于高，例如 PPT 导出的 PDF）不排双页：版面选了「双页」也一次只排一页，竖版页照常成对；整本都是横版页时，6.9 的「版面」一行灰掉。两页同高。按 PDF 顺序两两成对（1–2、3–4……），不为封面或章首插空白页，和 6.2 一致。
- **书眉**：样式同 6.3。单页显示章名；双页左页书名、右页章名；章首页不显示书眉。章名优先取 PDF 书签（目录）里这一页所属的那一条，没有书签时才按 6.3 的规则从页文字里找最近的标题。两样都没有就不显示书眉，不拿文件名凑。
- **页脚**：样式和位置同 6.3。出处页码写「第 50 页」，就是 `book.pageLabel`，和出处、讲解里的页码是同一个数（6.4）。原页上印着的「42」和页脚的「第 50 页」可能不一样，这一点先保持，改用印刷页码在「以后再说」里，两边一起改。「本章还剩 N 页」按上面同一个章名划分章；认不出章就不写这半边。
- **原页本身**：不加边框，不加阴影，不加圆角。浅色模式下纸面是 `pgPaper` 白，原页的白底和纸面连成一片，看起来就是这张纸上印的字。
- **深色模式**：原页不反色，不调亮度和色温，彩色的知识框、强调色照原样。原页作为一张浅色的页放在深色纸上，加圆角 `Radius.s`，不另外垫边（原页自己的页边白就是垫底）；书眉、页脚、批注记号照深色 token 画在原页外面的深色纸上。这和 6.5 插图在深色下的处理是同一个思路，只是整页不再额外留 8dp。
- **清晰度**：按实际显示尺寸 × 屏幕缩放（100%、150%）渲染，不再固定 1.5 倍后拉伸。窗口大小变了，先把旧图按比例拉伸顶着，停下 200ms 后重新渲染，版面不闪白。
- **加载**：页还没渲染出来时，用 TON-1658 的纸面占位，尺寸按原页宽高比先留好，到了直接替换，版面不跳。
- **选字、高亮、出处**：
  - 鼠标在原页文字上显示 I 形光标，拖选时选区底色用 V7 `selBg`，按行合并成矩形，不加圆角。选中后弹出的菜单和文字版是同一个。
  - 高亮用 `hl`，画在字框上，和文字版同色。
  - 批注记号画在原页外侧的页边空白里，和批注那一行同高；单页在右侧，双页各在外侧。
  - 打开出处时，被引的几行用 `hl` 框出来。翻页时翻到那一页；滚动时滚到那一页，让第一行落在屏幕上方 1/3 处。不加闪烁动画。
- **翻页和键盘**：同 6.2，用同一个翻页组件（TON-1671）和同一个翻页效果设置。翻页时一次翻一页（双页时一次两页），鼠标滚轮一格翻一页（同 6.2 的节流），减弱动态时直接换页。滚动时同 6.2 的滚动。
- **原版和文字版互相切换**：在阅读设置（6.9）的「视图：原版 / 文字版」里切，替换现在顶栏的「看原页」，顶栏不再单放按钮。从原版切到文字版，回到当前原页开头所在的排版页（6.4）；从文字版切回原版，回到当前排版页第一个字所在的原页。PDF 默认原版，EPUB、TXT、Markdown、Word 默认文字版，没有原版可看时阅读设置里不显示这一行。用户切过一次，这本书就记住他的选择。
- **改了什么**：原版成为 PDF 的默认视图后，6.2–6.4 的排版分页只用在文字版。6.3 的书眉、页脚、底栏在两种视图里是同一套组件，TON-1670 直接用 TON-1667 做好的，不另写一份。

### 6.7 文字版里的裁图块（显示规范，识别和裁切由 TON-1669 做）

裁图块是从原页上裁下来、嵌回文字版阅读顺序里的一块：表格、公式、知识框、边栏、示意图、双栏里的复杂区域。它和 6.5 的插图用同一套摆法，下面只写不一样的地方。

- **和文字串的关系**（硬约束，和 6.1 的逐位对应一致）：裁图块覆盖的那段原文仍然留在页文字里，偏移一个都不动；文字版只是不把这段字再排一遍，排版时把这一段当成一整块，画成裁图。这样同一段字不会出现两次，出处、高亮、批注落在这段里也照常有效。插图（6.5）本来就没有字，所以不涉及这一条。
- **裁多大**：在识别出的区域外面多留一圈原页白边，宽度按缩放后正好 8dp 换算回原页单位。这一圈白边就是 6.5 在深色下要垫的 8dp，所以深色模式不需要再另垫一层，框线和底色也不会被裁掉。
- **显示多大**：让块里的字和旁边的正文差不多大。缩放比 = 正文字号（18sp × Aa 缩放）÷ 这本书正文的中位字号（导入时从 PDF 文字层统计）。按这个比例放大后宽过版心的，缩到版心宽；高过版心高 85% 的，按比例缩小（和 6.5 一样）。缩小后块里的字如果小于 `Size.cap` 12sp，块下方右对齐写一行「点开看大图」（`Size.cap`，`fgTertiary`）。渲染分辨率按显示尺寸 × 屏幕缩放算，和 6.6 一样不拉伸位图。
- **对齐**：居中，和 6.5 一样。按上面的缩放，通栏的知识框和表格多数正好是版心宽，左右和正文边缘对齐。
- **和正文的间距看块的类型，不看是裁的还是渲染的**：公式和表格前后各 `Space.s3`（12dp），和 6.1「不缩进的块」相同；知识框、边栏、示意图、复杂区域前后各 `Space.s4`（16dp），和 6.5 插图相同。块后面那一段：如果块插在一段话中间（原文这里没有分段），接下来的字不首行缩进，接着上一句排；块正好在两段之间，下一段照 6.1 正常缩进。
- **不加东西**：不加图注、边框、阴影。表题、图注如果在裁的范围里，就跟着块一起显示；不在范围里的，仍是正文里的一行，照 6.1 排。
- **浅色和深色**：浅色模式下裁图的白边和 `pgPaper` 纸面连成一片，看不出边。深色模式下裁图不反色，不调亮度，作为一块浅色的块放在深色纸上，圆角 `Radius.s`。
- **分页**（翻页时；滚动时照原位放）：一块不从中间切开。
  - 知识框、边栏、示意图、复杂区域照 6.5 的插图挪：放不下就挪到下一页开头，空出来的地方用后面的正文补上，最多挪一页，不挪出本章。
  - 公式和表格不挪：它们常常就在一句话里，挪走会把句子拆开。放不下就从下一页开头接着排，这一页剩下的地方留白（公式一般只有一两行，空得不多）。
  - 比一页还高的块按 6.5 缩到 85%。缩完块里的字小于 `Size.cap` 12sp 的表格改成按行拆：结构渲染的表格（下面）按行拆到下一页，新页顶上重复表头；裁图的表格按 TON-1669 识别时一并给出的行边界切成几块，后面每一块顶上重复表头那一条裁图。跨了原页的大表格，先按原页裁成几块，各算一块。
  - 挪了位置的块，它覆盖的那段字仍按原文偏移算。拖选时选区按偏移走：从块前面的正文一路拖到补空的正文，中间被挪走的那一块会一起选上、一起高亮，这是对的。
  - 双页时同 6.5，块不跨书脊。
- **块里的字也能选、能高亮**：叠一层和 6.6 原版页同一种看不见的文字层，用 TON-1670 存的字框按裁切位置换算坐标。选区用 `selBg`，高亮用 `hl`，画在块里对应的字上。拖选可以从正文一路选过块再选到后面的正文。出处只落在块里时，整块再加一圈 `hl` 色的 2dp 外框（同 6.5），翻到块所在的排版页。
- **点开放大**：在块上单击、没有拖动时，打开 6.5 的那个覆盖层，按覆盖层的尺寸重新渲染，不拉伸。拖动是选字，不打开覆盖层。
- **结构可靠时直接渲染，不裁图**（EPUB、Word 本身带的结构，或方案比较后认定可靠的识别结果），样式走 V7：
  - 表格：只画横线，`line` 色 1dp（表头上下和表格最下面各一条），不画竖线；单元格左右 `Space.s2`、上下 `Space.s1`；字号 `Size.note` 15sp，数字列用 `LocalV7Fonts.numbers` 右对齐；表头用宋体。太宽时表格在块里横向滚动，用 `V7Scrollbar`，不压缩字号。
  - 公式：用仓库已有的 `MathAsset` 渲染，字号同正文，居中。
  - 知识框、边栏（EPUB `<aside>`、Word 带边框的段落）：底色 `card`，1dp `line` 边框，圆角 `Radius.s`，内边距 `Space.s4`。框里有标题的，标题用宋体加粗、和正文同字号，下面留 `Space.s2`。框里的段落照 6.1 排。
  - 结构渲染出来的块里的字本来就在文字串里，选字、高亮和正文完全一样，不需要文字层。
- **加载**：同 6.5，用纸面占位，尺寸先留好。

**验收看什么**（不设数字门槛）：

1. 偏移不变：每份样书每一页都核对显示串和原文等长，非空白字符逐位相同；原有的出处、高亮、批注测试全过，不改、不放宽。
2. 分页不丢字不重字：一章的所有排版页按顺序拼起来，正好是这一章的原文；窗口改大改小、字号调大调小后再核一遍。
3. 真窗口：在 winbox 打开样书，纯键盘翻 10 页、切一次单双页（拖窗口宽度）、打开一条出处、在阅读设置里切一次视图（原版 / 文字版）再切回来，截图或录屏。
4. 原版（TON-1670）：同一份样书 PDF 在 100% 和 150% 缩放下，翻页单页、翻页双页、滚动各截一张，浅色深色各一套；拖选一段，选区和文字版里同一段的偏移逐字一致。
5. 裁图块（TON-1669）：自己生成的测试 PDF（知识框、表格、公式、双栏）在文字版里，每种块和前后正文的间距、深色下的样子各截一张；块所在页的显示串仍和原文等长。
6. 翻页（TON-1671）：照 TON-1671 卡上的外部验证做。另外在本机把参照截图 35、36、37 和自己做出来的同一时刻并排比，写下哪里还差（参照图不进 Git、不上传）。
7. 阅读设置（TON-1672 和各行所属的卡）：6.9 的五条标准，每一行放出来之前都要过。

### 6.9 阅读设置

李政 11-16：「可以用简单的方式给用户多选择，但是每种选择都要打磨好。」所以选项少，默认就是最好的那个，大多数人不用打开设置。

- **入口**：阅读页顶栏现有的「Aa」。点开是挂在 Aa 下面的一块面板，不是下拉菜单，也没有二级页面，一屏看完。改了立刻生效，没有「确定」按钮。点面板外面或按 Esc 关闭。原来分散在顶栏的「翻页 / 滚动」「整页 / 页宽」「看原页」都收进来，顶栏只留 Aa。
- **选项**（从上到下；前四行管怎么翻，后三行管字和纸，两组之间一条 `menuSep` 细线）：

| 行 | 选项 | 默认 | 记在哪 | 什么时候灰掉 | 归哪张卡 |
| --- | --- | --- | --- | --- | --- |
| 视图（只有 PDF 有这一行） | 原版 / 文字版 | 原版 | 按书 | — | TON-1670（原版）、TON-1669（文字版保住排版） |
| 阅读方式 | 翻页 / 滚动 | 原版滚动，文字版翻页（EPUB、TXT、Markdown、Word 都是文字版） | 按书，原版和文字版各记一个 | — | TON-1671（组件和文字版），TON-1670（原版接同一组件） |
| 版面 | 自动 / 单页 / 双页 | 自动 | 全局 | 滚动时，下面小字写「滚动时只排一栏」；原版整本都是横版页时也灰掉，小字写「横版页一次排一页」 | 文字版 TON-1667，原版 TON-1670 |
| 翻页效果 | 翻转 / 滑动 / 无；卷页达标后加在最前，并成为默认 | 翻转 | 全局 | 滚动时；系统关了动画时不灰掉，下面小字写「系统已关闭动画，翻页会直接换页」 | TON-1671 |
| 字号 | 小 / 中 / 大（现有 0.9、1、1.15 倍） | 中 | 全局，重开应用还在 | 原版时，下面小字写「原版按原书大小显示」 | TON-1672 |
| 正文字体 | 宋体 / 楷体 | 宋体 | 全局 | 原版时 | TON-1672 |
| 纸色 | 跟随系统 / 浅 / 深 | 跟随系统 | 全局，整个应用一起变 | — | TON-1672 |

- **版面的三个值**：「自动」按 6.2、6.6 的分界。「单页」再宽也只排一页，居中。「双页」在不够分界时，先把正文栏从 33em 收窄，最窄 28em；原版则把两页一起按宽度缩小，原页宽不小于 360dp。还放不下就排单页，这一行下面写「窗口太窄，先排单页」。
- **字体**：楷体是 V7 已经打包的霞鹜文楷（`lxgw_wenkai.ttf`，OFL，V7 里用在批注），不新增字体文件。只换正文里的中文：西文仍是 Literata；标题、章号、书眉、页脚仍用 V7 原来的字体。两种字体都带 `chws`（已核对 GPOS），标点挤压照 6.1。两种都是常用字子集，子集外的字都回落系统字体；交付截图时找一处生僻字，核对回落后不突兀。
- **纸色不加暖纸**：V7 浅色的纸本来就摆在暖色桌面上。V7 现有的暖色纸 `sheet`（FCFAF6）和书页用的白 `pgPaper` 放在一起几乎看不出差别，做成选项等于没区别；真要米黄纸就得加新颜色，那就离开 V7 了。所以只有跟随系统、浅、深三种。
- **样子**：面板底色 `menuBg`，1dp `menuSep` 边，圆角 `Radius.m`，宽 360dp，内边距 `Space.s4`，行高 40dp。每行左边是行名（`Size.cap`，`fgTertiary`），右边是一排选项文字（`labelLarge`）。选中的那个用 `ink` 字、`pineWash` 底、圆角 `Radius.s`，没选中的用 `fgSecondary`。灰掉的行文字用 `fgTertiary`，原因写在下面一行小字里。不用图标，不用开关样式，不加预览图。
- **键盘**：Tab 能走到 Aa，回车打开；面板里 ↑ ↓ 换行，← → 换选项并立即生效，Esc 关闭，焦点回到 Aa。面板开着时方向键不翻页。
- **记住**：全局的存在本机设置里，不上传服务端；按书的和这本书的阅读进度存在一起。重开应用后照旧。
- **放出来之前的标准**：每一行、每个值都一样。没达到的就不出现在面板里，宁可少一个。
  1. 1920×1080 和 2560×1440 两个尺寸 × 浅色深色截图，每个值都有。
  2. 只用键盘能选上它，选上以后键盘照常翻页。
  3. 系统关了动画时表现合理（翻页效果见 6.2）。
  4. 和别的选项任意组合都不出错：写一个测试，把所有组合（视图 × 阅读方式 × 版面 × 翻页效果 × 字号 × 字体 × 纸色）在 1280×800 和 2560×1440 两个尺寸下都排一遍，不抛异常，文字版的每种组合都满足 6.8 验收第 1、2 条（显示串等长、分页不丢字不重字），原版的组合核对页框尺寸和单双页，不必渲染图。再挑三组最容易出事的截图：双页 + 原版 + 大字号；窄窗口 + 楷体 + 大字号 + 深色；滚动 + 版面设成双页（应当排一栏，版面那一行灰掉）。
  5. 「阅读方式」这一行另加：翻页和滚动功能对等，TON-1671 卡上的对等表（8 项功能，就是 6.2「滚动」里列的那 8 项，× 翻页、滚动 × 原版、文字版，共 32 格；PR #331 的 `docs/design/page-turn.md` 里是同一张表）逐格打勾，每格一张 winbox 真窗口截图（真实教材的截图只留本机）；两种方式来回切 10 次停在同一句；关掉重开还是上次的方式。
- **面板和各卡怎么分**：TON-1672 做面板本身、存取和自己那三行，并给其余每一行留一个开关，开始都关着。别的卡做完自己那一行、达到上面的标准后，只打开自己的开关，不改面板文件的其他地方。
