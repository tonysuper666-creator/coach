# 文字阅读保留特殊排版：本机方案比较

2026-11-16，TON-1669 第一阶段的推荐结论与证据。**四路比较仍有缺项，阅读器尚未验收。**

目标是让正文可以重排，同时让表格、公式、知识框和示意图保持原样，并保持既有出处、
高亮和批注的 UTF-16 偏移。用同一批真实教材页验证候选区域，而不是用模型标签数量
代替用户实际能读到的内容。

## 推荐结论与适用边界

**第二阶段采用 A 的既有文字 + B 的本机区域候选 + C 的几何补边 + 原页保底。**
现有证据足以选择这条实现路线；候选筛查结果不作为自动裁图上线或阅读器效果通过的依据。

| 路线 | 推荐承担的职责 | 选择依据与限制 |
|---|---|---|
| A：既有 PDFBox 文字提取 | 继续提供 `BookPage.text` 和 UTF-16 出处基准 | 保住已有高亮、批注、搜索的位置契约；A 本身不提供特殊块，也有错序和公式线性化风险 |
| B：本机 Docling | PDF 特殊块的主要区域候选来源；不接管正文 | 20 页完整候选 60/67，高于 C 的 24/67；但仍漏外框、轴标题和公式前缀，不能直接自动裁图 |
| C：PDFBox 绘制与字形几何 | 补外框、辅助核对候选边界及源文字范围 | 无须引入另一套文字串；现有原型漏表、拆公式，不作为独立默认识别器；B+C 联合效果未测 |
| D：远程 VLM | 本轮不接入默认链路 | 同页比较未执行，真实教材不得上传；不能据空白评价质量、成本或优于 B/C |

B 的文字若替换 A，会产生 14,705 个 code-point edit-script changed；这不是识字错误率，
却足以否决直接替换既有页字符串。B 的整页回退标记也不足以保证完整：计入回退后仅
62/67，还有 5 个漏裁对象所在页没有触发回退。必须验证完整边界、阅读方向、文字范围
和跨栏续段，不能只以模型标签或 `order_gate=ok` 放行。无法证明时保留原文与原版入口，
不静默隐藏正文；整表/原页保底仍不能算作长表按行分页或文字版排版验收通过。

对 EPUB/Word，优先保留源文件已有的表格、公式、知识框结构，可靠时直接渲染；
不先扁平化再靠 PDF 区域识别重建。工具已能保留源包结构载荷，仍须映射到现有页文字
并接入生产导入与存储；下文的提取实验不代表产品已支持。

这次选择的是实现路线。Windows 的安装分发方式另需产品测量：隔离 venv 加复制模型
约 2.18 GB，空应用缓存下载约 765 MB，两次测量范围不同，不能相加作为产品安装量。
干净系统/产品安装增量和真实教材的 Windows 速度仍未验证。真实双栏/页边注另补 4 页，
不与原 20 页混算；字符正确性、旋转表方向和 D 同页比较仍有缺口。

TON-1665 的统一页资产模型已随 PR #337 合入主干，下文直接沿用其字段和存储。
**第二阶段显示仍须等 TON-1667、TON-1670 的显示改动合并**；TON-1670 的导入/字框
PR #334 合并不等于显示前置完成。提取工具及下文生产映射回归均未开启自动裁图导入、
阅读器显示或共享 UI。

## 材料与方法

- 真实教材：同一本 620 页 PDF，选 20 个复杂物理页，SHA-256
  `43dc0c53b7a52fd074cafa7b05f324babaef4b6349dff2d8134a61971d971c04`。
- 页码固定为下表所列。覆盖知识/习题框、表格、多行公式、图像和并排图形；没有找到
  可作为双栏正文基准的页面，也没有单列足够的页边注样本。后续补样见下一节，原 20 页
  的数值与口径保持不变。不能外推到所有教材。
- Mac 本机读取原页并逐页看 Original/B/C 三列边界覆盖图。原文、PDF、JSON、坐标、
  标注与图片全部留在本机私有目录；仓库只存通用工具、数字和结论。
- 一个知识框作为一个对象，框内公式不重复计数；多面板图逐面板计数；连续推导算一组，
  独立相邻公式分别计数。共人工数得 67 个对象。
- “完整候选”要求一个候选矩形完整包住对象、必要坐标标签、公式行/编号及知识框标题与
  外框。边界模糊或裁掉一部分时按失败计；没有量化多裁正文的代价，也没有金标准坐标集。
  这是人工边界筛查，**不是实际裁图嵌入后的保住率**，需要独立复核。
- 在同一份 20 页原图、A 文字和 B 有序块上人工核对跨块阅读顺序，逐页结果见下表。
  这是已确认错序组的保守下限，不含表内单元格、单个公式内部次序和缺字；不是完整的
  阅读顺序正确率。C 原型沿用 A 的文字序列，计数相同，不代表渲染后的 C 已验证。
  D 仍为 null。Docling 的 `single_column/conflict/unknown` 只是自动门禁。

“Docling 没在真实教材上跑过”的原始前提不成立：TON-1424 已留下 10 本、1011 页的
真实材料记录。本次仍重新跑固定 20 页，不沿用那次速度或候选数量冒充本轮结果。

## 人工阅读顺序筛查

以原页的独立段落、表题、图注、图形和显示公式为逻辑块。A 看 canonical text；B 看
`reading_order` 排列的结构块，包括无文字的图/公式块，不是只看 diff 使用的文字串。
一个连续交错组计一次；同一图的标签和图注反复交错或轴标题晚到，不重复增加计数。
两个独立图各出错分别计数；公式字形插进两个独立正文段分别计数。位于表格上方的
表题落到表格后算一次。相邻浮动图放在完整段落前或后均可，插断同一段落才算错误。

不计页眉页脚、同一表格内部行列、同一公式内部上下标/分式线性化、缺字和重复文字。
这些仍可能导致不可读，不能以本列的 0 宣称页面可用。人工确认下限为 A 21 组/12 页、
B 17 组/10 页；C 与 A 相同，因为尚未生成独立的裁图/正文阅读流。没有独立复核，
也没有证明 B 的整体顺序比 A 好；两条流的结构和缺失内容不同。

可复核的反例：

- A：46 页并排表格互相穿插；184/189/547 页公式字形进入前一段正文；
  116/312/483 页图注或图片署名与相邻正文/标题穿插。
- B：46/49/247/272/312/483/493/544 页共 14 个表题落到表后；
  189 页两个独立公式被交错片段表示；483 页插图及图注插断同一正文段；
  536 页图注晚于标题、两段正文和一个习题表，累计 17 组。

私有 `review-private.json` 保存逐页计数和逐组说明，供在本机对照原页、A 文字和 B 块
复核。计数是人工观察，不能仅靠脚本或自动门禁重新生成。

## EPUB 元素到既有文字的映射

目标是让表格、MathML、知识框和样式节点能引用已有正文，同时保持出处、高亮和批注的
UTF-16 偏移。新增生产接口 `TextbookExtraction.epubSourceMapping(path, canonicalPages)`，
**按需调用，尚未接入自动导入、持久化或阅读器**。普通导入不生成该载荷。

原有 EPUB 提取遍历可选择记录元素的输出区间，之后沿用同一套 clean、trim 和 paginate。
映射使用被消费的连续文字切片，不用 `indexOf` 搜索句子；相同段落、相同章节和重复的
spine 引用也有独立位置。输出包括完整 OPF spine 的序号、包内成员名、成员原始字节的
SHA-256、从 XML 根开始的元素子节点索引路径、命名空间/标签，以及分散到各页的
`[start,end)` 范围。路径忽略文本、注释节点，与 `native_payload.py` 的源树对应；
使用源树时必须先核对成员摘要。`linear="no"` 的章节仍不生成正文或范围，但保留其
在完整 spine 中的位置，不能把筛选后的序号直接当作源包序号。

这些是**正文覆盖范围**：包含原提取器生成的标题标记和子块分隔符，不含元素自身的
外侧分隔符；父子元素范围会重叠，不能据此授权隐藏文字。空元素/仅含被修剪空白的
元素返回空范围，不猜图片锚点。跨页元素返回多段，每段仍指向原页串；不把 form-feed
或空页伪造成文字。清理偏移只保存需要的端点，不为章节中每个字符分配映射数组；
范围定位按页边界二分，再只遍历实际相交的页。

重提取后的全部页码和文字须与传入的 canonical pages 完全一致，否则返回
`STALE_TEXT` 和空载荷，不搜索相近位置。图像、字框等附加页字段不参与文字身份比较。
源包精确字节/树仍由已有 native payload 工具保留；本接口并未持久化这些结构、展开
CSS、导出行分页契约或渲染公式，也没有改 EPUB 的既有文字串或替换 TON-1665 模型。

## 表格切点与显式题注片段的补充证据

PR #348 已验收合并。本段从其后的主干 `76f5e256` 开始，只改提取实验、合成回归和
本文档，没有接入生产导入、页资产存储或阅读器。下列结果更新提取能力，不改前面
PR #345 的历史测量，也不把边界证据当作长表分页已完成。

原先只有完整 PDF 横线才能证实行切点。现在也允许两种受限证据：

- 同一高度、精确共线且相接的单元格边线可拼成跨表横线；有空隙、错高或多条候选线
  都不能靠猜测选一条。探针保留短边线，正文提取设置不变。
- 无横线时，必须有完整合法的单页网格，且表框中的每个字形全部落在唯一单元格内。
  每个单元格须从原页 canonical UTF-16 区间逐字回取，与模型单元格文字仅忽略空白后
  相等；不搜索重复词，不作字符归一化，区间重用、缺字、偏移不全或截断代理对均拒绝。
  只有模型相邻行之间的空白同时由实际字形间隔证实，才在间隔中间提供切点。

两种切点都不能穿过字形或跨行单元格；多页、旋转、裁剪未验证、图形不可靠仍不提供
切点。重复表头只取从表顶开始的连续表头行，并要求其末端恰有证实的切点。
`verified_boundaries` 仍只说明几何边界证据，不证明模型的语义行列一定正确，也不是
渲染或自动隐藏许可。

题注的 `source_parts` 按显式引用次序保留每个片段自己的框、范围和映射状态。
引用重复、缺失、类型不符或归属不唯一时不输出片段；只有各片段映射与版面顺序均
可信时才标 `source_parts_verified`。组的 `replacement_range` 永远为空；题注片段
之间夹着正文时保持分段，不能用一个包围区间吞正文。未标注的续段、图注在正文之外
的正确插入位置和去重仍没有解决；该状态也不证明 owner 的位置正确。

## 不依赖模型的显式跨页来源：PDF 标签与 MCID

PR #350 已验收合并。本段从其后的主干 `b25bab48` 开始，回应真实模型没有跨页
关联的问题：补充 PDF 原文件自带的结构来源，不按表头相似性猜续表。没有改模型
输出，也没有接自动裁图导入、持久化或显示。

### 来源与拒绝边界

`TaggedTableProbe.java` 读取同一个结构树 `Table` 下的 `TR` / `TH` / `TD`，
通过物理页 MCID 找到实际内容流中的文字。结构节点的父指针、页归属、MCID 正向
引用与 `ParentTree` 反向所有者必须一致；重复所有者或跨表复用不能认证。源路径
必须与文档 SHA-256 一起使用。只支持直接标准表层级，不支持角色映射、嵌套表、
跨行/跨列格、跨页单元格或表单流里的 MCID；缺标签不生成关联。

MCID 随同一 canonical stripper 的真实 `TextPosition` 对象经过排序和输出，而非
二次搜索文字。独立普通探针的文档摘要、全文、页框、完整字形偏移及框必须逐项一致。
重复 MCID 序列、字形合并或丢失、ActualText、表单、裁剪、旋转、未映射范围和
不安全页框均拒绝；单元格仍逐个核对精确 UTF-16 切片，不合并段间正文。

私有 `tagged_tables.py` 载荷标记 `source_kind=pdf_structure_tree_mcid`。
只有完整连续物理页、矩形网格、页内行带有序且切线不穿文字，才给
`verified_tagged_association`。预算同样限制为 500 行、32 页和 200 万次比较；
任一条件失败不交部分表。每格保留源路径、MCID、TH 标记、精确不连续区间和字形
外包框，每页保留原文摘要及文字安全行切点。该状态仅核实标签与字形对应，不证明
作者的语义标注正确。

**字形外包框不是裁图框。** 它不能保证边线、留白、底色或非文字对象完整，因而
`crop_ready=false`、`source_region=null`，不接入现有页资产。
`hide_source_allowed=false`，所有替代范围为空；`repeat_header=null`，只有 TH
来源标记，还没有可重复的表头图片。本路径与已有模型分片载荷分开，不改变旧结果。
