# Windows 朋友上手说明

- 安装包下载：〈私发时填入下载链接〉
- Mac 地址：〈私发时填入服务地址〉
- 你的六位邀请码：〈私发时填入这位朋友的码，保留开头的零〉

请在〈填入到期日期、时间和时区〉前完成一次配对。之后再打开软件，可以直接用。

1. 在 Windows 上下载安装包，双击安装，在开始菜单打开 LearningCoach。
2. 在配对页填入上面的 Mac 地址和六位码，点「配对」。如果已经进了书架，也可以在书的「讲解」页配对。
3. 导入一份自己的教材或文本，打开有正文的一页。选一段想了解的内容，点「讲解」，按提示确认是否同意发送选段。
4. 收到讲解后，点回答里的出处就能看引用的原文。

每人每天最多 100 次模型调用、100 万个输入和输出 token，按 UTC 零点重置。看到额度用完提示时，仍然可以在本机读书。配对失败时先核对地址和六位码，连续输错可能使邀请失效。需要新码或换电脑时，私下联系发给你邀请的人。
