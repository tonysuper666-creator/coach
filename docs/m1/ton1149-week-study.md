## 按周学习的范围与账本

目标是选一次周次后连续学，不再逐个找知识点再点开始。打开应用、点「按周学习」、选周，共 3 步；后续「下一个知识点」1 步。原知识点的「下一步 / 出题」保留，用来在同一个点内讲解或练习。

周次直接取 `outline_revised.knowledgePoints[].week`，没有该字段时取标题中的 `【Wn·…】` 标签（包括第二锚点及 `【Essay】` 后的标签）。当前课程已有标签，不新增推测的章节日历。课程数组顺序是导入器保存的原课程顺序；`ops.move` 按原有位置操作回放。跨周共用的点可以属于两周，掌握记录仍只有一份。

`set_study_scope` 由服务端生成本周未通过或需修复的队列，写 `study_scope_set`。`advance_study_scope` 写 `study_scope_advanced`，带范围事件 ID 和当前知识点：另一台设备已经推进或换周时返回冲突，避免旧页面跳过新进度。投影回放得到范围和游标，重启和换设备均走既有同步。选择「全部课程」写清除范围的事件。手动跳过只推进游标，不改变掌握状态。

通过的点自动从剩余队列移除。学习页收到通过投影且判分/回复结束后直接打开后继点；新点使用原有 `tutor.open` + `next`，继续走 TON-1139 的备课缓存与流式后备路径。今天卡片按目标是否打开过显示「回到 X（没学完）」或「开始下一个：Y」，过滤已通过的旧线程目标。

一周结束显示实际通过数，提供「再练这一周错题」和「换下一周」；最后一周没有下一周时可在周选择器换周。周错题出口只列本周最新一次仍答错的选择题，用已复核原题、新 attempt ID、重新分配的字母和服务端判分重练。重复原题不会变成新的首次作答通过证据；也不改变周队列游标。未提供构答题重练。
