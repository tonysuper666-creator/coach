## 口径

频次只数用户回合。一条保留下来的精通会话，54 条用户消息，2026-10-28T18:31:56Z 至 2026-10-29T21:20:14Z。更早的模型调用原文已经不在会话库里，不计数。分类只用 `tools/corpus/prepare-replay.py` 的 `intent()`，不把没匹配上的自由发言再并进「问概念」。工具调用次数和自然日不进频次列。

三种时间分开写：

- 端到端：手机上从发出打开或点按，到屏幕上出现该动作的目标文字。取「目标文字已经在画面里」的那一张截图的开始时刻，所以写出来的秒数是上界。0.6 秒的画面里还没有，0.9 秒的画面里有，就写成 0.9 秒。写动作没有在他的 DeepTutor 账号上重做。
- 后台：冻结快照上的时间戳。回合墙钟是 `turns.finished_at - turns.created_at`，只含已完成、且消息元数据里带了该回合 id 的行。工具出现时间是该回合里该工具第一次 `tool_result` 减去回合 `created_at`。中位数用两个中间值的平均（偶数个时）；p90 用 nearest rank，`sorted[ceil(n*0.9)-1]`。
- 推算：这一轮没有用推算填秒数。

比较规则：两侧都有同一种端到端秒数才分更好、持平、不如。较慢的一侧不超过较快一侧的 1.2 倍，记持平；超过则较快的一侧更好。只有一侧有端到端，记待验证。页面本身不存在，记缺。后台秒数不拿来减端到端秒数。

Coach 的讲解池是另一次冻结：测试库里 `task=TEACH` 且 `status=complete` 的 46 行，首字中位 4439.5 毫秒、p90 8314 毫秒，整轮中位 7232.5 毫秒、p90 11316 毫秒。这是一整池，不能拆给「提问」或「接着学」。账本里提交到判分的差是 0 毫秒的那些行，是同一条记录，不是屏幕上看到对错的时间。

题库有两份，不要混：教学调用那份快照是 33 题、5/49 个知识点；拿去开隔离服务端的生产库副本是 40 题、6/49 个知识点。

复算请对着冻结快照跑，不要查活库，也不要查这次手机实测写过的那份运行副本。验收脚本的三个数在这份快照上是：`intent()` 为 answer 28 / unknown 20 / question 3 / continue 2 / request_batch 1；`mastery_grade` 中位 28.415 秒（p90 42.432，n=28）；`read_source` 中位 19.536 秒（p90 24.905，n=3）。±20% 对的是这几个冻结中位数。单次新调用、单张手机截图，以及「落在 p90 里」，都不是这个标准。

这次 Coach 端到端跑在当前 main 上。比较分支已合入 `acdd016`，服务端包是 2026-10-31 16:08:29 打出来的，`nextStep` 的签名是两个 boolean。隔离服务在 18811，桥副本在 8802，库是生产库副本。手机包是 `com.coach.android` 0.1.0（versionCode 1），lastUpdateTime 2026-10-31 15:45:24，Android 树与这次 main 一致。生产端口 18791 和桥 8791 的进程没有换过。测完后桥日志字节数仍是 0，作业表仍是已完成 26、失败 1，没有新的排队作业。没有点「开始讲解」「下一步」「继续」「换个例子再讲」，也没有发「期中学了多少」。

DeepTutor 端到端仍是 2026-10-31 在同一台 PMA120 上用系统 Chrome 打开 `3790` 只读页。第一张有效截图的等待：聊天首页 2.6 秒，精通总览 2.8 秒（已显示 9/49 与 18%），练习页 2.6 秒（108 道待复习、32 道等下次、题库 140）。知识库列表 3.1 秒（1 个库、120 篇），资料列表 3.1 秒（53 份）。这些是直接打开地址，记 1 步。点进一份资料后 5.8 秒仍是「正在打开文档」，正文没量到。没有点「开始复习」「继续学习」或任何发送。

## 修补优先级

先补缺的。秒数只写已经量到的。

1. 题库覆盖到全部知识点。现在生产库副本是 6/49，教学调用快照是 5/49。没题的知识点上，「出题」做不成。已经有题的知识点上，点「出题」到 3 道题出现，上界 0.6 秒。相对那 1 次明确要求出题的后台出卡（74.9 秒，n=1）能快多少，两边不是同一种时间，这一项仍不写节省秒数。
2. 学习页能打开原文。DeepTutor 的资料列表 3.1 秒内已经可见。Coach 学习页没有原文入口。系统代读的 19.5 秒是另一件事，不能记成这一项省下的时间。
3. 按错题复习的页。DeepTutor 练习页 2.6 秒内能看到待复习题数。Coach 的复习页 0.4 秒内打开，上面是空的知识点队列和 0 道离线题。本周冻结库里没有判错行，不能把「再讲一轮」的回合墙钟当成这项的收益。

已经量出的差距只在两处，而且是同一个画面：重新打开后 0.9 秒内能看到进度数字和「继续」，DeepTutor 总览上的对应文字是 2.8 秒。大约少 1.9 秒。
