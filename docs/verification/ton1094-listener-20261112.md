# TON-1094：绑定失败不阻塞回环认证

2026-11-12，原 PR18；基线 `af2cb248d1eaf317838f2778e04995c78ec5cd86`。检查时最新 main `f81e9258b02c622772e0aca3df35c0a6ff5ec7af` 仍使用同步启动；本轮授权仅改 Main 中 Tailscale 监听器启动一行及同范围回归。

`Main` 的 Tailscale 重试协程与账本 actor 共享主事件循环。Netty 绑定失败时，同步 `start(wait = false)` 的失败清理会同步等待事件组关闭，阻塞该循环。改为 `startSuspend(wait = false)`，让 Ktor 的挂起启动桥处理阻塞工作。异常处理、退避、取消和认证均保留。
