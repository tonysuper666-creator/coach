# 五个画像复测（每版出包的固定一步）

一条命令，在 winbox 的真窗口上跑。不改产品。教材原文、截图、凭据、服务地址、配对码不进 Git。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\smoke\persona-retest.ps1 -Exe <本版安装目录>\LearningCoach.exe
```

`-Exe` 指向这一版安装包展开后的 `LearningCoach.exe`（jpackage 的安装版，不是 `gradlew run`）。不传则用本检出 `desktopApp\build\compose\binaries\main\app\LearningCoach\LearningCoach.exe`。脚本拒绝指向本机已经装好的正式目录。身份已经写在各画像自己的主目录里，脚本不读、不打印，表上只写「已配置」。提问里的汉字用键盘的 Unicode 按键送入；Windows 的 SendKeys 送不出汉字。

跑完在证据目录打印一张表：每个画像做成几步、卡在哪一步，讲解失败率、提问失败率、崩溃/窗口，和上一版并排。上一版数字来自 `tools/smoke/persona-retest-baseline.json`（只有数字）。没有这份文件时，上一版写「无」，本跑就是基线。

失败率的五类和四舍五入与 `tools/dev/version-rates.py` 相同：超时、额度、拒答、出处、其他。崩溃写成「次数/打开的窗口」，对应 TON-1917 的「崩溃次数/活跃设备天」。这张表数的是本轮窗口里看到的成败。服务端 `counts.json` 仍由主会话在 hermes 上跑 `version-rates.py`，脚本不代跑。

截图和日志留在 `D:\agent\evidence\persona-retest\<时间>\`。表里每个没通过的检查都能对上这个目录里的一张图。

## 谁来跑

出包时由 winbox 上的 Scout-Grok 对这一版安装包跑上面那条命令，把表贴到当版的卡上。验收者照同一份清单另跑一个画像，和表里那一行对上。朋友七步仍由出包验收者跑，不和这一步并成同一个人。

## 五个画像

窗口最大约 820×620，这是这台机器开得出的尺寸，窗口小本身不算失败。一次只开一个画像。看到「上次异常退出」只点「不发」。

| 画像 | 原话里要做的事 | 通过 | 身份 | 主目录 |
|---|---|---|---|---|
| P1 备考 | 把教材放进要考的课，看今天学什么，做题，问两章差在哪 | 打开已登录的首页；倒计时、拨日期、计时模考、长篇跑题四项见下 | 已配置 | `D:\agent\personas\P1\home-r2` |
| P2 朋友 | 把小说放进去读，点一句让它讲，再自己打一句问 | 进了书；讲解有结果；提问框用键盘打得出字并发出 | 已配置 | `D:\agent\personas\P2\home-r2` |
| P3 睡前 | 接着昨晚的图读，问一句这页的图在说什么 | 进了书；提问有结果 | 已配置 | `D:\agent\personas\P3\home-r2` |
| P4 综述 | 打开我的库，点一条对比回到原句 | 库里点到对比后进了书 | 已配置 | `D:\agent\personas\P4\home-r2` |
| P5 挑刺 | 强杀再开，书还在，不把记录发出去 | 重开后仍是已登录首页；点了「不发」 | 已配置 | `D:\agent\personas\P5\home-r2` |

P1–P5 每次都从共享主目录复制到 `证据目录\homes\Px`，再清掉这一份里记下的「上次停在阅读页」。共享主目录只读，不写回，也不改 Windows 日期。窄窗口阅读页左上角只有「←」。还停在阅读页时点它离开；离开不了记「没离开阅读页」，首页上没有「我的库」记「没看到我的库」。只有进了库、点了「对比」、列表是空的，才记「库里没有对比」。

讲解或提问看到这些字，就记进对应的失败类：超时；额度或配额；依据不足或无法确认（拒答）；出处对不上；连不上或暂时不可用（其他）。先出现「正在」再给出正文，记成功。

## 固定进清单的真窗口检查

| 检查 | 怎么算通过 | 卡在别处 |
|---|---|---|
| 首页倒计时（TON-1912） | 副本里把考试日设到 14 天后，首页出现「距考试 14 天」，并有一行「新学 … 个考点 · 复习 … 道错题 · 做 … 道题」 | 没有课程或没有考试日 |
| 拨日期重排（TON-1912） | 不改系统日期。把副本的考试日改到 11 天后，重开后变成「距考试 11 天」，任务仍是一行，分钟数不超过「每天最多」 | 倒计时那一步没过 |
| 计时模考到点交卷（TON-1912） | 找到「计时作答」，时长改成 1 分钟，开始后等到「计时结束，已自动交卷。」 | 只有按课程时长出的卷，或入口不在 |
| 对比表出处高亮（TON-1922） | 「我的库」里筛「对比」，点开一条后进了书。那一句有没有被高亮，看这一步的截图 | 没离开阅读页，没看到我的库，没看到对比，或库里没有对比 |
| 长篇跑题不判答到（TON-1919） | 本章开放题里交一份固定的跑题句（不抄书）：晚饭是番茄炒蛋和米饭。吃完去楼下走了二十分钟，又看了一会儿新闻。判点出现「没答到」，不出现「这一点答到了」 | 开放题没出来 |

## 退出码

| 码 | 意思 |
|---|---|
| 0 | 这次点名的画像步骤都走完，这些画像负责的检查都通过。没点名的不要求 |
| 1 | 跑完了，有画像没走完，或它负责的检查没通过。表仍然印出 |
| 2 | 没开跑：桌面被占用，或安装版打不开 |
